# Rehab Fit – AI-Powered Physiotherapy Monitoring System

**A wearable-based machine learning system for shoulder physiotherapy exercise recognition and monitoring.**

## About the Project

Rehab Fit is an engineering project that combines wearable motion sensors, machine learning and a web-based application to support shoulder physiotherapy monitoring.

The system uses motion data collected from an IMU sensor to identify shoulder exercises, classify movement patterns and support repetition monitoring.

## Project Objectives

- Recognise shoulder physiotherapy exercises using wearable sensor data.
- Apply machine learning to classify movement patterns.
- Monitor exercise repetitions.
- Explore real-time feedback for physiotherapy exercises.
- Develop an accessible wearable-based rehabilitation monitoring solution.

## Technologies

- Python
- Scikit-learn
- NumPy and Pandas
- React
- FastAPI
- ESP32
- WT901BLE 9-axis IMU sensor
- Bluetooth Low Energy (BLE)

## Machine Learning Models

The project explores and evaluates:

- Support Vector Machine (SVM)
- K-Nearest Neighbours (KNN)
- Random Forest
- Extra Trees Classifier

## Model Evaluation

The final evaluated models achieved the following results:

| Model | Accuracy |
|---|---:|
| Linear SVM | 96.30% |
| KNN | 94.21% |
| Random Forest | 92.19% |
| Extra Trees | 91.21% |

## System Components

1. Wearable motion sensor for movement data collection.
2. Data preprocessing and feature extraction.
3. Machine learning-based exercise classification.
4. Backend API for prediction and application communication.
5. Frontend dashboard for displaying exercise information.

## Project Status

Academic engineering project. The machine learning models have been evaluated using the collected dataset. Further real-world testing and validation are required.
